# 实时天气数据获取

从不同天气的API抓取天气信息，主要关注温湿度能见度空气质量等内容，记录间隔1小时

## 1.和风天气v2

实时天气API获取数据晚上出现低温，疑似不准，

从格点天气API抓取数据缺少能见度，，经纬度定位，数据1h整点更新

空气质量API抓取aqi等数据，

**缺少能见度，获取数据较准？**

## 2.最美天气

从动态网页抓取url，模拟网页获取信息，原始数据过大，仅感兴趣部分的内容

该站点有长光所对应的城市id，可定位到长光所

**初始有一段时间风速值不变，数据不稳定**

## 3.彩云天气

免费API，部分风力等级，风向等数据需要自己计算得到，天气描述使用编码，需要转换，

能见度达到了60，其他能见度在30左右，**能见度不准**

## 4.和风天气v3

从格点天气API抓取数据缺少能见度，后实时天气API补齐，经纬度定位，数据1h整点更新

空气质量API抓取aqi等数据，

**实时天气和格点天气两者对比，未确定哪个更不准？**
